# 이동호 (Dongho Lee)

쇼핑몰 연동 엔진을 만들고, AI 코딩 에이전트 도구에 기여하는 개발자입니다.

## 지금 하는 일

- **쇼핑몰 연동 엔진**: 여러 오픈마켓의 상품, 주문, 문의 API를 하나의 형식으로 묶는 엔진을 TypeScript(Node.js)로 만들고, C#과 PHP 레거시 엔진을 유지보수합니다.
- **Orca 오픈소스 기여**: 여러 코딩 에이전트를 나란히 돌리는 데스크톱 앱 [Orca](https://github.com/stablyai/orca)에 Kiro CLI 지원을 중심으로 기여하고 있습니다.
- **개인 프로젝트**: 개인 비서 앱과 홈 서버 도구를 만들어 직접 씁니다.
